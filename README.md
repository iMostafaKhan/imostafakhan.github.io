# Mustafa Khan — Portfolio

A lightweight responsive portfolio website.

## Files
- `index.html` — complete website
- `assets/profile.jpg` — profile photo cropped from the supplied CV

## Free hosting with GitHub Pages
1. Create a GitHub account and a new repository.
2. Upload `index.html` and the `assets` folder.
3. Open Settings → Pages.
4. Select “Deploy from a branch”, choose `main` and `/root`.
5. GitHub will provide a free `github.io` website address.

No paid hosting or domain is required.
